## Native mathematics

- Astronomy Engine stays at pinned **2.1.19**, unmodified MIT C source. Original bulk ABI is now **2**, with an illuminated-fraction field. The serial Dart worker envelope also carries optional station and magnetic-model results; this is separate from the C ABI.
- Frozen checks: **1,166** JPL position samples (including event-grid positions), maximum **0.335458303 arcmin**; **144** Astropy stellar samples, **0.307578464 arcmin**; **72** Astropy DSO samples, **0.427525002 arcmin**. Existing 1-arcminute limits and two explicitly unsupported near-pole cases are unchanged. C/JS parity: 1,166 comparisons, maximum **1.42109×10⁻¹³ degrees**. Native rise/set/event search is still outside this implementation.
- SGP4: official Vallado AIAA 2006-6753 archive/source/results, SHA-pinned and cited. **63** TEME position/velocity reference rows across near-Earth, drag and resonant cases; maximum coordinate residual **4.92219×10⁻⁹ km**, velocity **4.98347×10⁻¹⁰ km/s**, reflecting agreement with the rounded reference output. **Nine** independent Astropy observer comparisons under matched UT1=UTC/zero-polar-motion assumptions, maximum **9.09226×10⁻⁸ degrees**. These are implementation checks, not orbital-data error bounds.
- WMM2025: official NOAA/NCEI public-domain C core and 2025 coefficients; deterministic coefficient transcription verified during asset staging. **12** official field/declination samples and three invalid-date rejections; maximum declination residual **0.004614825°** against the rounded table. Valid only **2025 ≤ year < 2030**. Automatic correction requires current context, adequate sensor quality, model horizontal field ≥6,000 nT and model declination uncertainty ≤2°. Example locations do not automatically establish physical pointing. Manual known-reference alignment remains available.
- WMM output estimates the main geomagnetic field. It cannot remove phone-case/metal/field-storm/device errors. Assumed zero ellipsoidal height stays explicit. The model's small numerical residual is not the phone's accuracy.

## Public ISS contract

`GET /api/v1/catalog/satellites/iss` returns a versioned provenance packet or explicit `503 Satellite.ElementsUnavailable` with `no-store`. The packet carries NORAD 25544, source URL, original OMM JSON and SHA-256, epoch/retrieval/expiry, TEME/UTC/SGP4 conventions. No observer or account is submitted. The server shares last-good public data through Redis plus memory; Redis failure does not invalidate an otherwise usable packet. Source fetches are coalesced and attempted no more frequently than two hours, including failures.

The client checks digest, conventions, identity, numeric bounds and times, then stores only this non-personal public packet in an application-support public-catalogue file. Its lifetime ends **72 hours after element epoch**; source maneuvers/drag can reduce usefulness earlier. Invalid/stale/unavailable data removes the station direction; no synthetic point or bundled “current ISS” elements are used. Propagation uses WGS72 gravity, AFSPC mode, WGS84 geodetic observer and approximate UT1=UTC/zero polar motion, without refraction, visibility/sunlit-pass guarantees or operational tracking claims.

## Resources, privacy and source rights

Sky background decodes to 1024 pixels wide (about 2 MiB RGBA); solar textures to 256 pixels; at most 12 decoded 512-pixel figure textures are retained, with at most eight nearby figures requested. These are code budgets, not measured physical GPU/RSS/FPS results. Initial public asset staging verifies **106** canonical assets, including existing photos/audio/art and the 8,228,817-byte ESO large JPEG. Restricted 800-megapixel source is excluded. The public data/photo/code source hashes are preserved byte-for-byte by Git attributes.

Original implementation is Apache-2.0. Astronomy Engine is MIT; catalogue, photo, Free Art License figures, Chris Zabriskie audio, ESO CC BY 4.0, Vallado use permission and WMM public-domain notices remain separate and accessible offline. Exact owner screenshots are private ignored reference material, not product assets.

No microphone, background-location or external-storage permission is present in the inspected APK. Coordinates/pose/alignment and personal records are not persisted or uploaded. Only notice/mute UI preferences and the explicitly non-personal expiring ISS packet are local. Native verified-account/secure-token/account-language/notebook parity remains SKY-06 work; this feature does not create a private offline queue.
