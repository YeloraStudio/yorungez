# Public astronomy knowledge

`guides.json` contains original, paired English/Turkish educational guides. These are deliberately curated articles, rather than automatically generated pages for every catalogue object. Original text follows the repository Apache-2.0 licence; linked third-party sources and reused archive images retain their own rights.

Keep both languages, stable slugs, source links and the real editorial review date together. Use primary scientific sources, distinguish calculated position from visibility and illustrative imagery, and avoid fabricated author credentials, rankings, live-data claims or observer-specific instructions without the observer/time context. Content corrections can be proposed in the public repository without disclosing personal observations or coordinates.

Web pages are generated statically, with server-visible content, reciprocal language links, canonical URLs and sourced Article metadata. Images come from the existing verified media catalogue with credits/licence links; competitor screenshots and private data are not reused.

`indexnow.json` and the matching public root text file are a **public host-ownership proof**, not a secret or a server API credential. Run `python scripts/submit_indexnow.py` to review the canonical public URL list; add `--submit` only after the corresponding Web version and proof file are live. An accepted submission does not guarantee indexing. Google does not use this submission endpoint.
